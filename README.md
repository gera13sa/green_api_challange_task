# Тестовое задание для GREEN-API Герасимов А. Д.

## Локальный запуск

Запуск проекта для разработки.

Используемая версия ноды: v22.22.2

* Выполнить `npm install`
* Создать файл `.env` по примеру содержимого `.env.example`
* Выполнить `npm run dev`
* Проект запустится по адресу http://localhost:5173/

## Локальная сборка в статику

Сборка проекта в статические .js + .html + .css файлы для развертывания

* Выполнить `npm install`
* Создать файл `.env` по примеру содержимого `.env.example`
* Выполнить `npm run build`
* Сборка будет находиться в папке `dist`


## Сборка докер образа

Сборка и запуск в виде докер контейнера

* Создать файл `.env` по примеру содержимого `.env.example`
* Выполнить `docker compose up -d`
